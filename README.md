# Keybindings Image Generator

## Background

This script helps create a Keybindings Image on a keyboard with bindings for
Qtile.

It is a fork of [their script](https://github.com/qtile/qtile/blob/master/scripts/gen-keybinding-img).
Changes have been made to make it less Qtile centric.

## Goals

The goal is publish a structure for how keybindings can be read in and allow
using virtually any tool to create images for the keybindings of an app.

## Install

* Install python-pillow python-cairocffi
* Download the gen-keybinding-img script and run: ./gen-keybinding-img -h
